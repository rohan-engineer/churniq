How Predictions Work

Transparent, End-to-End Pipeline Transformation

  1. Validation: Input bounds and data types are verified against the training schema.
  2. Pipeline Transformation: Numerical features are standardized and categorical fields are One-Hot Encoded using the serialized preprocessor.
  3. Neural Network Forward Pass: Input passes through 2 dense layers with ReLU & Dropout to produce the sigmoid probability.
  4. Decision & Explanation: Thresholding assigns the churn class, and domain logic maps behavioral drivers.
